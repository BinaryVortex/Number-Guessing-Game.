# Number Guessing Game

![Game Screenshot](Screenshot%202024-07-02%20150409.png)

A small, browser-based number guessing game built with HTML, CSS and JavaScript. Guess the secret number and try to get it right with as few attempts as possible.

## Demo
- Open `index.html` in your browser to play locally.

## How to play
1. The game chooses a secret number between 1 and 100 (configurable in the script).
2. Enter your guess in the input field and press the "Check" button.
3. The game will tell you whether your guess is too high, too low, or correct.
4. Keep guessing until you find the secret number. Your score decreases with incorrect guesses.

## Features
- Simple, clean UI with responsive layout.
- Real-time feedback: too high / too low / correct.
- Score tracking for attempts.
- Restart the game without reloading the page.

## Files
- `index.html` — markup and basic structure
- `style.css` — styling and layout
- `script.js` — game logic
- `Screenshot 2024-07-02 150409.png` — project screenshot used in this README

## Development / Customize
- Change the range or number of allowed attempts in `script.js` (look for the variables near the top).
- Improve styling in `style.css` or add new UI elements.
